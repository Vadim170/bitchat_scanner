# BitChat Scanner - Руководство по использованию режимов сканирования

## Доступные режимы сканирования

BitChat Scanner поддерживает два режима сканирования BLE устройств:

### 1. Сканирование в приложении (IN_APP)
**Когда использовать:**
- Для быстрого поиска устройств
- Когда приложение открыто и вы активно используете его
- Для экономии батареи (автоматически останавливается при закрытии)

**Характеристики:**
- ✅ Работает только когда приложение открыто
- ✅ Автоматически останавливается при выходе из приложения
- ✅ Не показывает постоянное уведомление
- ✅ Меньше расход батареи
- ❌ Не работает в фоне

**Как запустить:**
1. Откройте приложение
2. Нажмите кнопку "Scan in App"
3. Сканирование начнется немедленно

### 2. Фоновое сканирование (SERVICE)
**Когда использовать:**
- Для длительного мониторинга сети
- Когда нужно продолжить сканирование с закрытым приложением
- Для получения уведомлений о новых устройствах

**Характеристики:**
- ✅ Работает в фоновом режиме
- ✅ Продолжает работать при закрытом приложении
- ✅ Может отправлять уведомления о новых обнаружениях
- ✅ Постоянное уведомление показывает статус
- ❌ Больший расход батареи

**Как запустить:**
1. Откройте приложение
2. Нажмите кнопку "Background Service"
3. Появится постоянное уведомление
4. Можете закрыть приложение - сканирование продолжится

## Переключение между режимами

**Важно:** Одновременно может работать только один режим сканирования.

При запуске нового режима предыдущий автоматически останавливается:
- IN_APP → SERVICE: IN_APP останавливается, запускается SERVICE
- SERVICE → IN_APP: SERVICE останавливается, запускается IN_APP

## Остановка сканирования

### Остановка IN_APP режима:
1. Нажмите "Stop In-App Scan" в приложении
2. ИЛИ закройте приложение - остановится автоматически

### Остановка SERVICE режима:
1. Откройте приложение
2. Нажмите "Stop Service"
3. ИЛИ смахните уведомление (если поддерживается)

## Проверка текущего режима

В главном окне приложения отображается:
- **Нет кнопок остановки** = сканирование не активно
- **"Stop In-App Scan"** = активен IN_APP режим
- **"Stop Service"** = активен SERVICE режим

## Уведомления о новых устройствах

Для получения уведомлений о каждом обнаруженном устройстве:
1. Включите переключатель "Notify about detections"
2. Предоставьте разрешение на уведомления (Android 13+)
3. Уведомления будут приходить в обоих режимах

**Примечание:** В SERVICE режиме уведомления продолжат приходить даже при закрытом приложении.

## Часто задаваемые вопросы

### Какой режим выбрать?
- **Быстрый поиск** → IN_APP
- **Длительный мониторинг** → SERVICE
- **Экономия батареи** → IN_APP
- **Работа в фоне** → SERVICE

### Можно ли запустить оба режима одновременно?
Нет, это предотвращено на уровне архитектуры. Одновременно работает только один режим.

### Что происходит с данными при переключении?
Все обнаружения сохраняются в базе данных независимо от режима. При переключении режимов данные не теряются.

### Сколько устройств можно обнаружить?
В базе хранится до 1000 последних обнаружений. При превышении автоматически удаляются самые старые записи.

### Влияет ли режим на точность GPS?
Нет, оба режима используют одинаковую логику определения местоположения (GPS + Network + Passive).

## Разрешения

Для работы сканирования требуются разрешения:

### Android 12+ (API 31+)
- ✅ BLUETOOTH_SCAN - для сканирования BLE
- ✅ BLUETOOTH_CONNECT - для подключения к устройствам
- ✅ ACCESS_FINE_LOCATION - для GPS координат

### Android < 12 (API < 31)
- ✅ ACCESS_FINE_LOCATION - для BLE сканирования и GPS

### Опционально
- ACCESS_COARSE_LOCATION - альтернатива FINE_LOCATION
- POST_NOTIFICATIONS (Android 13+) - для уведомлений

Все разрешения запрашиваются при первом запуске приложения.

## Расход батареи

Примерный расход батареи (зависит от устройства):

| Режим | Расход батареи | Примечание |
|-------|----------------|------------|
| IN_APP | ~1-2%/час | При активном экране |
| SERVICE | ~3-5%/час | В фоновом режиме |

**Совет:** Для экономии батареи используйте IN_APP режим когда активно используете приложение, и SERVICE только для длительного мониторинга.

## Техническая информация

### Параметры сканирования
- **Режим сканирования:** LOW_LATENCY (максимальная частота)
- **Фильтрация:** По BitChat service UUID
- **Интервал сохранения:** Каждое обнаружение
- **Максимум записей:** 1000

### Broadcast события
Приложение отправляет следующие события:
- `ACTION_SCANNER_STARTED` - сканирование запущено
- `ACTION_SCANNER_STOPPED` - сканирование остановлено
- `ACTION_LOG_LINE` - новое обнаружение

### Архитектура
Подробнее о внутренней архитектуре см. в файлах:
- `ARCHITECTURE.md` - общая архитектура приложения
- `REFACTORING_SUMMARY.md` - детали рефакторинга сканирования

## Устранение неполадок

### Сканирование не запускается
1. Проверьте, что Bluetooth включен
2. Убедитесь, что предоставлены все необходимые разрешения
3. Перезапустите приложение
4. Проверьте лог событий в меню приложения

### Не приходят уведомления
1. Проверьте переключатель "Notify about detections"
2. Предоставьте разрешение POST_NOTIFICATIONS (Android 13+)
3. Проверьте настройки уведомлений Android
4. Убедитесь, что уведомления не отключены для приложения

### Service не останавливается
1. Откройте приложение
2. Нажмите "Stop Service" явно
3. Если не помогает, принудительно остановите приложение в настройках Android

### Устройства не обнаруживаются
1. Убедитесь, что рядом есть устройства с BitChat
2. Проверьте, что устройства включены и анонсируют BLE service
3. Проверьте UUID сервиса: `f47b5e2d-4a9e-4c5a-9b3f-8e1d2c3a4b5c`
4. Попробуйте перезапустить сканирование
